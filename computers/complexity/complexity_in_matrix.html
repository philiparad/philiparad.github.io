1. הגדרת גודל הקלט במערך דו־ממדי

מערך דו־ממדי מורכב משורות ומעמודות. נגדיר n כמספר השורות ו־m כמספר העמודות. מספר התאים הכולל הוא n·m.

דוגמה: 3 שורות × 4 עמודות = 12 תאים.

מערך ריבועי

n=m ולכן מספר התאים n².

n × n = n²

מערך מלבני

מספר השורות והעמודות עשוי להיות שונה.

n × m = nm

הבחנה חשובה: אפשר להגדיר גם N=nm כמספר התאים הכולל. סריקה מלאה היא O(N), או O(nm) אם מנתחים לפי שני הממדים. במערך ריבועי היא O(n²) כש־n מציין את אורך הצלע.

3. דוגמאות קוד — גישה, שורה, עמודה

דוגמה 1 — גישה לתא

הפעולה אינה תלויה בממדי המערך.

int x = arr[2, 3];
O(1)

דוגמה 2 — מעבר על שורה אחת

בשורה יש m תאים.

for (int j = 0; j < m; j++)
{
    Console.WriteLine(arr[0, j]);
}
O(m)

דוגמה 3 — מעבר על עמודה אחת

בעמודה יש n תאים.

for (int i = 0; i < n; i++)
{
    Console.WriteLine(arr[i, 0]);
}
O(n)

4. סריקה מלאה ולולאות עוקבות

דוגמה 4 — שתי לולאות מקוננות

n חזרות חיצוניות, ובכל אחת m חזרות פנימיות.

for (int i = 0; i < n; i++)
{
    for (int j = 0; j < m; j++)
    {
        Console.WriteLine(arr[i, j]);
    }
}
T(n,m)=nm ⇒ O(nm)

דוגמה 5 — שתי לולאות עוקבות

הראשונה רצה n פעמים והשנייה m פעמים.

for (int i = 0; i < n; i++)
    Console.WriteLine(arr[i, 0]);

for (int j = 0; j < m; j++)
    Console.WriteLine(arr[0, j]);
T(n,m)=n+m ⇒ O(n+m)

5. אלכסון וסריקה משולשת

דוגמה 6 — אלכסון ראשי

סורקים n תאים בלבד מתוך n².

for (int i = 0; i < n; i++)
{
    Console.WriteLine(arr[i, i]);
}
T(n)=n ⇒ O(n)

דוגמה 7 — מספר החזרות תלוי ב־i

בסיבוב i מבוצעות i+1 פעולות; סוכמים 1+2+...+n.

for (int i = 0; i < n; i++)
{
    for (int j = 0; j <= i; j++)
    {
        Console.WriteLine(arr[i, j]);
    }
}
T(n)=n(n+1)/2 ⇒ O(n²)
זהירות: גם אם לא נסרקים כל התאים, הסיבוכיות יכולה להישאר ריבועית. בדקו את מספר הפעולות ולא רק את חלק המערך שנסרק.

6. המחשה אינטראקטיבית — ממדים ומסלול הסריקה

שנו את מספר השורות והעמודות, ובחרו איזה חלק של המערך נסרק. התאים הכחולים הם התאים שבהם מתבצעת פעולה.

באלכסון של מערך מלבני יש min(n,m) תאים. בסריקה משולשת, אם שתי המידות שונות, מספר התאים הנסרקים תלוי בשתיהן. במערך ריבועי מתקבל O(n²).

7. טעויות נפוצות ושיטת פתרון

טעות: כל מערך דו־ממדי מחייב O(n²).
תיקון: שגוי: גישה לתא בודד היא O(1), שורה אחת O(m).
טעות: שתי לולאות תמיד נותנות O(n²).
תיקון: שגוי: יש להבחין בין עוקבות למקוננות, ובין n לבין m.
טעות: סריקה של מערך n×m היא בהכרח O(n²).
תיקון: שגוי: בסריקה מלאה O(nm); בריבוע n×n מתקבל O(n²).
טעות: אם פעולה מתבצעת רק בחלק מהתאים, סופרים רק את הפעולות שבוצעו.
תיקון: לא תמיד: אם בכל תא נבדק תנאי, גם בדיקות התנאי נחשבות.

חמישה שלבים לפתרון שאלה

  1. הגדירו n כמספר השורות ו־m כמספר העמודות.
  2. זהו מה בדיוק מתבצע בכל איטרציה.
  3. מנו את מספר החזרות בכל לולאה, לרבות בדיקות תנאי.
  4. כתבו פונקציה למספר הפעולות T(n,m).
  5. פשטו וקבעו חסם אסימפטוטי באמצעות O.
