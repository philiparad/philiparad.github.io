Modes and setup

Everything is entered through the calculator. MODE opens the LCD mode menu; press 1–6 to choose an item, ◀/▶ for pages. In multi-field screens, enter a value, press = to advance, and AC to exit. SHIFT → MODE opens LCD setup.

Press MODE, then a numbered key (1–6). Use ▶ for the next menu page and ◀ to return. SHIFT + MODE opens SETUP. AC exits. Use only calculator buttons for calculations.

CASIO emulator keyboard shortcuts: F1 = SHIFT, F2 = ALPHA, F3 or Home = MODE, F4 = ON; Enter = equals, Backspace/Delete = DEL, arrows = REPLAY, Space = AC, and digits/operators type normally. With the calculator case focused, Tab = AC (Shift+Tab leaves the case). Browser controls keep standard keyboard navigation. Ctrl+C or Ctrl+Insert copies the LCD when clipboard permissions allow it.
