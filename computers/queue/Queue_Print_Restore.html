Educational Queue API

This example assumes a provided Queue<T> class with Insert(), Remove(), Head(), and IsEmpty(); these names differ from standard .NET and Java library queues.

Algorithm logic

  1. Remove one item from the main queue.
  2. Print it and insert it into the temporary queue.
  3. Move every item back, preserving the original order.
