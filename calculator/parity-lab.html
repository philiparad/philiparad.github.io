Physical-device evidence

For an authentic comparison, execute identical key sequences in a genuine calculator or appropriately licensed model-specific CASIO emulator, capture its LCD and key log, and pair them with the browser evidence from the test runner. An emulator screenshot is not a photograph of genuine hardware; record the source honestly.

The uploaded ZIP contained the fx-991ES PLUS C 2nd edition Windows emulator and its guide. It is not evidence for the original fx-991ES or non-C PLUS model. No proprietary DLL, executable or license file is published by this project.

See reference/device-parity/README.md for the CLI browser suite, evidence validation, model manuals and acceptance checklist.
