לולאה מקוננת היא לולאה שנמצאת בתוך לולאה אחרת. בדרך כלל הלולאה החיצונית מייצגת rows / groups, והלולאה הפנימית מייצגת columns / items. בכל ריצה אחת של החיצונית, הפנימית מתחילה מחדש ומבצעת את כל הריצות שלה.
הדגש במסמך זה: לא רק לוח כפל וריבוע כוכביות, אלא בעיקר תבניות שבהן טווח הלולאה הפנימית תלוי במונה החיצוני: משולשים, אלכסונים, זוגות ייחודיים, צוברים לפי שורה וקלט בכמות משתנה.

1. מפת הנושא — ממה בנויה לולאה מקוננת?

מרכיבתפקידתבנית חשיבה
לולאה חיצוניתקובעת את מספר הקבוצות, השורות, התלמידים, הימים או החנויות.for (int i = 1; i <= rows; i++)

מעבר שורהנמצא אחרי הפנימית, אבל עדיין בתוך החיצונית. מתאים להדפסת טבלאות ותבניות.Console.WriteLine();

כלל מרכזי לזכירה

1החיצונית נכנסת פעם אחת לשורה או לקבוצה.
2הפנימית מסיימת את כל הריצות שלה לפני שהחיצונית מתקדמת לערך הבא.
3אם הפנימית היא while, חובה לאתחל ולקדם את המונה הפנימי בכל ריצה של החיצונית.

תבנית בסיסית: שתי לולאות for קבועות

static void PrintTable(int rows, int cols)
{
    for (int i = 1; i <= rows; i++)      // outer: rows
    {
        for (int j = 1; j <= cols; j++)  // inner: columns
        {
            Console.Write(i + "," + j + "	");
        }
        Console.WriteLine();             // end of current row
    }
}

תבנית for + while: כאשר מספר הריצות ידוע אבל רוצים לולאת תנאי

static void PrintTableForWhile(int rows, int cols)
{
    for (int i = 1; i <= rows; i++)
    {
        int j = 1;                       // reset inner counter
        while (j <= cols)
        {
            Console.Write((i * j) + "	");
            j++;                         // progress inner loop
        }
        Console.WriteLine();
    }
}

טעות נפוצה: אם שוכחים את j++, הלולאה הפנימית לא תסתיים.

2. מתי בוחרים for ומתי while?

מצבבחירה מומלצתסיבה
ידוע מראש כמה פעמים לחזורforהאתחול, תנאי העצירה וקידום המונה נמצאים באותה שורה.
עוברים על שורות ועמודות קבועותfor + forמתאים לטבלה, מטריצה, לוח כפל, ריבוע כוכבים.
קולטים עד סימן סיוםwhileמספר הריצות אינו ידוע מראש, לדוגמה קליטת ציונים עד -1.
לכל קבוצה מספר פריטים אחרfor + whileהחיצונית עוברת על הקבוצות, הפנימית נעצרת לפי תנאי משתנה.

static void PrintDiagonals(int n)
{
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            if (i == j || i + j == n + 1)
                Console.Write("* ");
            else
                Console.Write(". ");
        }
        Console.WriteLine();
    }
}

איפה מאתחלים את הצובר?

סכום שורה וסכום כללי

static void PrintRowSumsAndTotal(int rows, int cols)
{
    int totalSum = 0;

    for (int i = 1; i <= rows; i++)
    {
        int rowSum = 0;                  // reset for current row

        for (int j = 1; j <= cols; j++)
        {
            int value = i * j;
            rowSum = rowSum + value;
            Console.Write(value + "	");
        }

        totalSum = totalSum + rowSum;
        Console.WriteLine("| " + rowSum);
    }

    Console.WriteLine("Total = " + totalSum);
}

rowSum מתאפס בכל שורה. totalSum אינו מתאפס בתוך החיצונית.

static void PrintAveragePerGroup(int groups, int valuesInGroup)
{
    for (int i = 1; i <= groups; i++)
    {
        int sum = 0;

        for (int j = 1; j <= valuesInGroup; j++)
        {
            Console.Write("Enter value " + j + " for group " + i + ": ");
            int value = int.Parse(Console.ReadLine());
            sum = sum + value;
        }

        double avg = (double)sum / valuesInGroup;
        Console.WriteLine("Average for group " + i + " = " + avg);
    }
}

8. קלט מרובד: לכל תלמיד מספר אחר של ציונים

כאן החיצונית עוברת על התלמידים, אך הפנימית אינה יודעת מראש כמה ציונים יהיו. לכן משתמשים ב־while עם סימן סיום.

תבנית for + while עם זקיף

static void ReadGradesUntilMinusOne()
{
    int excellentCount = 0;

    for (int student = 1; student <= 40; student++)
    {
        int sum = 0;
        int count = 0;

        Console.Write("Enter grade for student " + student + ": ");
        int grade = int.Parse(Console.ReadLine());

        while (grade != -1)
        {
            sum = sum + grade;
            count++;

            Console.Write("Enter grade for student " + student + ": ");
            grade = int.Parse(Console.ReadLine());
        }

        if (count > 0)
        {
            double avg = (double)sum / count;
            Console.WriteLine("Average = " + avg);

            if (avg >= 90)
                excellentCount++;
        }
        else
        {
            Console.WriteLine("No grades");
        }
    }

    Console.WriteLine("Excellent students = " + excellentCount);
}

הציון הראשון נקלט לפני ה־while, ובסוף כל סיבוב קולטים שוב. כך התנאי מתעדכן.

static int CountMultiplesInTable(int rows, int cols, int divisor)
{
    int count = 0;

    for (int i = 1; i <= rows; i++)
    {
        for (int j = 1; j <= cols; j++)
        {
            int value = i * j;
            if (value % divisor == 0)
                count++;
        }
    }

    return count;
}

static bool ExistsProduct(int size, int target)
{
    bool found = false;

    for (int i = 1; i <= size; i++)
    {
        for (int j = 1; j <= size; j++)
        {
            if (i * j == target)
                found = true;
        }
    }

    return found;
}

static int FindMaxValue(int groups, int valuesInGroup)
{
    Console.Write("Enter first value: ");
    int max = int.Parse(Console.ReadLine());

    for (int i = 1; i <= groups; i++)
    {
        for (int j = 1; j <= valuesInGroup; j++)
        {
            Console.Write("Enter value: ");
            int value = int.Parse(Console.ReadLine());

            if (value > max)
                max = value;
        }
    }

    return max;
}
