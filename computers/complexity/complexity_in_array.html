עיקרון: גודל הקלט הוא מספר האיברים, אך הסיבוכיות מתארת את מספר הפעולות שהאלגוריתם מבצע כתלות ב־n. עצם השימוש במערך אינו קובע את הסיבוכיות.

איך מחשבים סיבוכיות?

  1. מגדירים במפורש את n .
  2. בוחרים פעולה בסיסית לספירה (השוואה, הדפסה, החלפה וכדומה).
  3. מונים חזרות, כולל תלות בין לולאות ותנאי עצירה.
  4. כותבים T(n) ומפשטים לסדר הגודל האסימפטוטי.
דיוק חשוב: ‏O הוא חסם עליון. בדוגמאות להלן מוצגת משפחת הגידול המקובלת; כאשר יש חסם הדוק אפשר לסמן גם Θ. לרוב בשאלות לימוד מציינים O של זמן הריצה במקרה הגרוע.

2. משפחות סיבוכיות נפוצות

סיבוכיות כיצד נוצרה דוגמה במערך
O(1) מספר פעולות קבוע גישה ל־ arr[k]
O(n) מעבר יחיד על כל האיברים סכימה או מציאת מקסימום
O(n²) שתי לולאות עד n השוואת כל זוג איברים
O(n³) שלוש לולאות עד n בדיקת כל שלשת אינדקסים
הסיבוכיות הנלמדות: זמן קבוע O(1) וזמן פולינומיאלי O(n), O(n²), O(n³) וכן O(nᵏ) עבור חזקה קבועה k. אין כאן ניתוח של פונקציות גידול שאינן פולינומיאליות.

3. זמן קבוע וליניארי

דוגמה 1 — גישה לתא יחיד 

int x = arr[3];

פעולת גישה אחת למיקום תקין, ללא תלות במספר התאים.

\(T(n)=1 \Rightarrow O(1)\)

דוגמה 2 — מציאת סכום האיברים 

int sum = 0;
for (int i = 0; i < arr.Length; i++)
{
                sum += arr[i];
}

יש n חזרות; בכל חזרה עבודה קבועה.

\(T(n)=an+b \Rightarrow O(n)\)

דוגמה 3 — שתי לולאות עוקבות 

for (int i = 0; i < n; i++) Print(arr[i]);
for (int j = 0; j < n; j++) Print(arr[j]);

יש 2n פעולות הדפסה ולא n², כי הלולאות אינן מקוננות.

\(T(n)=2n \Rightarrow O(n)\)

4. סיבוכיות ריבועית וקובייתית

דוגמה 6 — כל זוג אינדקסים 

for (int i = 0; i < n; i++)
{
                for (int j = 0; j < n; j++)
                                Compare(arr[i], arr[j]);
}

עבור כל אחד מ־n איברים מבוצעות n השוואות.

\(T(n)=n\cdot n=n^2 \Rightarrow O(n^2)\)

דוגמה 7 — רק זוגות שבהם j גדול מ־i 

for (int i = 0; i < n; i++)
{
                for (int j = i + 1; j < n; j++)
                                Compare(arr[i], arr[j]);
}

מספר ההשוואות הוא (n−1)+(n−2)+…+1.

\(T(n)=\frac{n(n-1)}{2} \Rightarrow O(n^2)\)

דוגמה 8 — שלוש לולאות מקוננות 

for (int i = 0; i < n; i++)
                for (int j = 0; j < n; j++)
                                for (int k = 0; k < n; k++)
                                                Count++;

שלושה אינדקסים עצמאיים, כל אחד מקבל n ערכים.

\(T(n)=n^3 \Rightarrow O(n^3)\)
הכללה: כאשר מתבצעות k לולאות מקוננות שכל אחת רצה n פעמים, כאשר k קבוע, מתקבלות nᵏ פעולות ולכן O(nᵏ). למשל ארבע לולאות מקוננות: O(n⁴). כאשר הלולאות עוקבות ולא מקוננות מחברים את מספר הפעולות.

דוגמה 12 — חיפוש סדרתי

אם האיבר הראשון מתאים — השוואה אחת. אם אינו נמצא — n השוואות. תחת הנחה שמיקום האיבר המבוקש אחיד — מספר השוואות ממוצע פרופורציונלי ל־n.

6. מעבדה אינטראקטיבית — השוואת גדילה

שנו את מספר איברי המערך ובחרו משפחת סיבוכיות. ההדמיה מציגה מספר פעולות מודליות (ולא מדידת זמן בפועל).

מודל ההשוואה מציג את מספר הפעולות עבור 1, n, n² ו־n³. המדידה אינה זמן הרצה אלא כמות פעולות תיאורטית.

7. כללי עבודה וטעויות נפוצות

טעות: שתי לולאות תמיד יוצרות O(n²)

בלולאות עוקבות מחברים: n+n=2n ולכן O(n). בלולאות מקוננות יש לבחון את גבולות הלולאה הפנימית.

טעות: חיפוש במערך תמיד O(n)

בחיפוש סדרתי, הסיבוכיות במקרה המיטבי O(1), ובמקרה הגרוע O(n).

טעות: מעבר על חצי מערך הוא O(1)

אם עוברים על n/2 איברים, מספר הפעולות גדל עם n ולכן O(n).

טעות: O(2n) שונה אסימפטוטית מ־O(n)

גורמים קבועים אינם משנים את סדר הגודל: O(2n)=O(n), וכך גם O(5n²)=O(n²).

שיטת פתרון: (1) להגדיר n; (2) לספור ביצועים; (3) לבדוק תלות בין הלולאות; (4) להבחין בין מקרים; (5) לרשום O מתאים ולנמק.
