Educational Queue API

The code uses an educational Queue<T> with Insert(), Remove(), Head(), IsEmpty(); it is not the built-in .NET/Java queue API. Marker values are reserved and excluded from the initial data.

Algorithm logic

  1. Insert a unique marker at BACK, then Remove() from FRONT.
  2. While the item is not the marker: print it, then Insert() at BACK.
  3. Stop when the marker reaches FRONT; the original order is restored.
