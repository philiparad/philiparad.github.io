תרגול: גזירת פונקציות שורש

דף עבודה מתוקן בעברית ובכתיב מתמטי תקין. בכל התרגילים יש להשתמש בכלל השרשרת.

הנחיות עבודה

  • בכל תרגיל מצאו תחילה את תחום ההגדרה של הפונקציה.
  • לאחר מכן גזרו את הפונקציה.
  • לבסוף ציינו את תחום ההגדרה של הנגזרת.
כלל עזר
\( \text{If } f(x)=\sqrt{u(x)}\text{, then } f'(x)=\dfrac{u'(x)}{2\sqrt{u(x)}}\text{, where } u(x)>0. \)

הערה: תחום ההגדרה של הנגזרת מחייב שהביטוי שבתוך השורש יהיה חיובי ממש.
