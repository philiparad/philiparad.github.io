Reference methodology

Internal unit tests assess implementation consistency. Manual-based seeds describe expected documented behavior but do not establish that this device/emulator has been observed. Physical and emulator records require an identified source and observation date. A passing comparison shows agreement with a stored observation, not universal Casio compatibility.

For reproducibility, record the exact model, angle and number-format settings, key sequence, display output, and any error text. The renderer uses a custom font, so framebuffer hashes compare only to the project's own images and are not evidence of pixel identity with Casio hardware.
