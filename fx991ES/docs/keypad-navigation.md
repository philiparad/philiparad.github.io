# Milestone 24 — Keypad and editing

SHIFT+DEL or INS toggles insert/overwrite. Overwrite replaces plain tokens only. DEL is backward deletion; FDEL is an optional forward-delete teaching shortcut, not a physical Casio key. Forward delete enters populated templates or removes empty templates whole. ALPHA+SIN/COS/TAN maps D/E/F, NEG maps A, and parenthesis keys map X/Y. SHIFT+SIN retains inverse-sine entry. These descriptors require real-device comparison before claiming compatibility.
