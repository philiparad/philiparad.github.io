1. הגדרת גודל הקלט במערך חד־ממדי

מערך חד־ממדי הוא רצף של תאים. נסמן n — מספר האיברים במערך (arr.Length ב־C#).

עיקרון: גודל הקלט הוא מספר האיברים, אך הסיבוכיות מתארת את מספר הפעולות שהאלגוריתם מבצע כתלות ב־n. עצם השימוש במערך אינו קובע את הסיבוכיות.

איך מחשבים סיבוכיות?

  1. מגדירים במפורש את n.
  2. בוחרים פעולה בסיסית לספירה (השוואה, הדפסה, החלפה וכדומה).
  3. מונים חזרות, כולל תלות בין לולאות ותנאי עצירה.
  4. כותבים T(n) ומפשטים לסדר הגודל האסימפטוטי.
דיוק חשוב: ‏O הוא חסם עליון. בדוגמאות להלן מוצגת משפחת הגידול המקובלת; כאשר יש חסם הדוק אפשר לסמן גם Θ. לרוב בשאלות לימוד מציינים O של זמן הריצה במקרה הגרוע.

3. זמן קבוע וליניארי

דוגמה 1 — גישה לתא יחיד

int x = arr[3];

פעולת גישה אחת למיקום תקין, ללא תלות במספר התאים.

\(T(n)=1 \Rightarrow O(1)\)

דוגמה 2 — מציאת סכום האיברים

int sum = 0;
for (int i = 0; i < arr.Length; i++)
{
    sum += arr[i];
}

יש n חזרות; בכל חזרה עבודה קבועה.

\(T(n)=an+b \Rightarrow O(n)\)

דוגמה 3 — שתי לולאות עוקבות

for (int i = 0; i < n; i++) Print(arr[i]);
for (int j = 0; j < n; j++) Print(arr[j]);

יש 2n פעולות הדפסה ולא n², כי הלולאות אינן מקוננות.

\(T(n)=2n \Rightarrow O(n)\)

4. זמן לוגריתמי ושורשי

דוגמה 4 — חיפוש בינארי (מערך ממוין)

int left = 0, right = arr.Length - 1;
while (left <= right)
{
    int mid = left + (right - left) / 2;
    if (arr[mid] == target) break;
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
}

בכל איטרציה תחום החיפוש מצטמצם בקירוב לחצי. במקרה הגרוע מספר הצעדים לוגריתמי; במקרה המיטבי ניתן למצוא במעבר הראשון.

\(O(\log n) \text{ במקרה הגרוע}\)

דוגמה 5 — מעבר על קידומת באורך שורש n

for (int i = 0; i * i < n; i++)
{
    Print(arr[i]);
}

הערכים i המקיימים i²<n הם בערך √n ערכים (בהנחה n>0).

\(O(\sqrt{n})\)

5. סיבוכיות ריבועית וקובייתית

דוגמה 6 — כל זוג אינדקסים

for (int i = 0; i < n; i++)
{
    for (int j = 0; j < n; j++)
        Compare(arr[i], arr[j]);
}

עבור כל אחד מ־n איברים מבוצעות n השוואות.

\(T(n)=n\cdot n=n^2 \Rightarrow O(n^2)\)

דוגמה 7 — רק זוגות שבהם j גדול מ־i

for (int i = 0; i < n; i++)
{
    for (int j = i + 1; j < n; j++)
        Compare(arr[i], arr[j]);
}

מספר ההשוואות הוא (n−1)+(n−2)+…+1.

\(T(n)=\frac{n(n-1)}{2} \Rightarrow O(n^2)\)

דוגמה 8 — שלוש לולאות מקוננות

for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        for (int k = 0; k < n; k++)
            Count++;

שלושה אינדקסים עצמאיים, כל אחד מקבל n ערכים.

\(T(n)=n^3 \Rightarrow O(n^3)\)

6. סיבוכיות n log n והבדלים חשובים

דוגמה 9 — n פעולות בכל רמת חלוקה

for (int step = 1; step < n; step *= 2)
{
    for (int i = 0; i < n; i++)
        Work(arr[i]);
}

מספר ערכי step הוא בערך log₂n, ובכל ערך מתבצעות n פעולות.

\(T(n) = n\lceil\log_2 n\rceil \Rightarrow O(n\log n)\)
קשר למיון מיזוג: חלוקת המערך לשניים יוצרת כ־log n רמות; בכל רמה פעולת המיזוג על כלל האיברים עולה O(n), ולכן זמן הריצה O(n log n).
לא כל לולאה בתוך לולאה היא O(n²): אם הלולאה הפנימית מבצעת רק log n פעולות, נקבל O(n log n). אם היא נעצרת במהירות כתלות בנתונים, יש לבחון את המקרה הנבדק.

7. סיבוכיות מעריכית ועצרתית — להעשרה

דוגמה 10 — כל תתי־הקבוצות (n קטן)

for (long mask = 0; mask < (1L << n); mask++)
{
    ProcessSubset(mask);
}

לכל איבר שתי אפשרויות: להיכלל או לא להיכלל. יש 2ⁿ מסכות. הקוד תקף רק ל־n קטן דיו כדי שההזזה והטווח יהיו תקינים, ונניח שעיבוד המסכה קבוע.

\(O(2^n)\)

דוגמה 11 — כל התמורות

GenerateAllPermutations(arr);

באופן מושגי, יש n! סידורים אפשריים. אם מבקרים בכל תמורה בעבודה קבועה, מספר הביקורים Θ(n!). אם גם מדפיסים n איברים בכל תמורה, הזמן Θ(n·n!).

\(\Theta(n!) \text{ ביקורים};\quad \Theta(n\cdot n!) \text{ להדפסה}\)
הבחנה: אלה סיבוכיות של אלגוריתמים מסוימים הפועלים על מערך; אין להסיק שמערך חד־ממדי עצמו מחייב זמן מעריכי או עצרתי.

8. מקרה מיטבי, גרוע וממוצע

דוגמה 12 — חיפוש סדרתי

int index = -1;
for (int i = 0; i < n; i++)
{
    if (arr[i] == target)
    {
        index = i;
        break;
    }
}

אם האיבר הראשון מתאים — השוואה אחת. אם אינו נמצא — n השוואות. תחת הנחה שמיקום האיבר המבוקש אחיד — מספר השוואות ממוצע פרופורציונלי ל־n.

\(\text{מיטבי } O(1);\quad \text{גרוע } O(n);\quad \text{ממוצע } O(n)\)

חיפוש בינארי במערך ממויןO(1)O(log n)

9. מעבדה אינטראקטיבית — השוואת גדילה

שנו את מספר איברי המערך ובחרו משפחת סיבוכיות. ההדמיה מציגה מספר פעולות מודליות (ולא מדידת זמן בפועל).

לצורך השוואה נבחרו פונקציות מייצגות: 1, ⌈log₂n⌉, ⌈√n⌉, n, n·⌈log₂n⌉, n², n³, 2ⁿ, n!. במימוש אמיתי מספר הפעולות עשוי להיות שונה בקבועים ובאיברים מסדר נמוך.

10. כללי עבודה וטעויות נפוצות

טעות: שתי לולאות תמיד יוצרות O(n²)

בלולאות עוקבות מחברים: n+n=2n ולכן O(n). בלולאות מקוננות יש לבחון את גבולות הלולאה הפנימית.

טעות: חיפוש במערך תמיד O(n)

חיפוש סדרתי הוא O(n) במקרה הגרוע; חיפוש בינארי במערך ממוין הוא O(log n) במקרה הגרוע.

טעות: מעבר על חצי מערך הוא O(1)

אם עוברים על n/2 איברים, מספר הפעולות גדל עם n ולכן O(n).

טעות: O(2n) שונה אסימפטוטית מ־O(n)

מתעלמים מגורמים קבועים: O(2n)=O(n). לעומת זאת O(2ⁿ) היא משפחה מעריכית.

שיטת פתרון: (1) להגדיר n; (2) לספור ביצועים; (3) לבדוק תלות בין הלולאות; (4) להבחין בין מקרים; (5) לרשום O מתאים ולנמק.
