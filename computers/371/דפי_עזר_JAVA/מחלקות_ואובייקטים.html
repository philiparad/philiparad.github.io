מחלקה היא תבנית ליצירת אובייקטים. אובייקט הוא מופע בפועל של המחלקה. אם arr.length = n, האינדקסים החוקיים הם 0 ≤ i < n. בתא ריק של מערך אובייקטים הערך הוא null.
בדף זה משתמשים במערכים רגילים בלבד. לא משתמשים ב־ArrayList, לא בירושה ולא בפולימורפיזם. כל פעולה על תא במערך אובייקטים חייבת לבדוק קודם שהתא אינו null.

2. תבנית מחלקה בסיסית

מחלקת Student עם שדות, פעולה בונה, פעולות גישה ו־toString

class Student
{
    private String name;
    private int id;
    private int grade;

    public Student(String name, int id, int grade)
    {
        this.name = name;
        this.id = id;
        this.grade = grade;
    }

    public String getName()
    {
        return name;
    }

    public int getId()
    {
        return id;
    }

    public int getGrade()
    {
        return grade;
    }

    public void setGrade(int grade)
    {
        if (grade >= 0 && grade <= 100)
            this.grade = grade;
    }

    public String toString()
    {
        return "Student: " + name + ", id: " + id + ", grade: " + grade;
    }
}

למה משתמשים ב־this?

this מציין את האובייקט הנוכחי. כאשר שם הפרמטר זהה לשם השדה, משתמשים ב־this.name כדי להבהיר שמתכוונים לשדה של האובייקט.

static void compress(Student[] arr)
{
    int next = 0;

    for (int i = 0; i < arr.length; i++)
    {
        if (arr[i] != null)
        {
            arr[next] = arr[i];

            next++;

    }
}

static void sortByGradeDescending(Student[] arr)
{

    for (int i = 0; i < arr.length - 1; i++)

10. הוספה והזזה לפי count

כאשר משתמשים במשתנה count, החלק הפעיל של המערך הוא רק 0 ≤ i < count. התאים מ־count והלאה אינם חלק מהרשימה הפעילה.

הוספה לסוף האזור הפעיל

static int addAtEnd(Student[] arr, int count, Student s)
static int addAtEnd(Student[] arr, int count, Student s)
{
    if (count < arr.length)
    {
        arr[count] = s;
        count++;
    }
    return count;
}

הכנסה למקום מסוים עם הזזה ימינה

static int insertAt(Student[] arr, int count, Student s, int index)
static int insertAt(Student[] arr, int count, Student s, int index)
{
    if (count == arr.length || index < 0 || index > count)
        return count;

    for (int i = count; i > index; i--)
        arr[i] = arr[i - 1];

    arr[index] = s;
    count++;
    return count;
}

סריקה נכונה כאשר יש count

for (int i = 0; i < count; i++)
{
    System.out.println(arr[i]);
}

אם כל האובייקטים נשמרים ברצף בתחילת המערך, אין צורך לבדוק null בתוך האזור הפעיל.

13. הכלת מערך אובייקטים בתוך מחלקה

מחלקת Course שמכילה מערך תלמידים

class Course
{
    private String name;
    private Student[] students;
    private int count;

    public Course(String name, int maxStudents)
    {
        this.name = name;
        this.students = new Student[maxStudents];
        this.count = 0;
    }

    public boolean addStudent(Student s)
    {
        if (count == students.length || s == null)
            return false;

        students[count] = s;
        count++;
        return true;
    }

    public int getCount()
    {
        return count;
    }
}

פעולה פנימית שסורקת את המערך שבתוך המחלקה

public double averageGrade()
public double averageGrade()
{
    int sum = 0;

    for (int i = 0; i < count; i++)
        sum += students[i].getGrade();

    if (count == 0)
        return 0;

    return (double)sum / count;
}

פעולה פנימית שמחזירה עותק, לא הפניה ישירה

public Student[] getStudentsCopy()
public Student[] getStudentsCopy()
{
    Student[] copy = new Student[count];

    for (int i = 0; i < count; i++)
        copy[i] = new Student(students[i]);

    return copy;
}

שגיאות שכדאי לזהות מיד

1שכחה לכתוב new בעת יצירת אובייקט.
2יצירת מערך אובייקטים וחשיבה שהתאים כבר מלאים.
3קריאה ל־arr[i].getGrade() בלי לבדוק arr[i] != null.
4שכחה לעדכן count אחרי הוספה או מחיקה.
5העתקת מערך אובייקטים בצורה רדודה כאשר נדרש עותק עמוק.

בדיקות קצה מומלצות

1מערך ריק לחלוטין.
2מערך מלא ללא מקום פנוי.
3חיפוש מזהה שלא קיים.
4מחיקה של האיבר הראשון, האחרון והיחיד.
5מיון כאשר יש ציונים שווים.
כלל עבודה מומלץ: לפני כתיבת פעולה על מערך אובייקטים החליטו האם עובדים עם count או עם בדיקות null. ערבוב בין שתי הגישות בלי תכנון הוא המקור הנפוץ ביותר לשגיאות.
